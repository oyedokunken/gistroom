# Decisions

Decision log. Newest at the bottom. Defaults D1 to D13 live in CLAUDE.md Section 27.

| ID  | Date       | Decision                                                                                                                                                                                                       | Reason                                                                                                                                                                              |
| --- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D14 | 2026-10-10 | Graphik is loaded with one `next/font/local` family and `preload: false`.                                                                                                                                      | `next/font` cannot preload only two weights of one family. Preloading all seven would cost about 250 KB on every page. Revisit with a manual preload link for Regular and Semibold. |
| D15 | 2026-10-10 | Graphik lacks naira, Yoruba, Igbo and Hausa letters and the combining marks (544 glyphs only). Self-hosted Noto Sans subsets (latin, latin-ext, vietnamese) are the declared fallback through `unicode-range`. | Result of `npm run lint:font`. User names must never render as boxes.                                                                                                               |
| D16 | 2026-10-10 | Only the seven Graphik weights in use were copied (Regular, Regular Italic, Medium, Semibold, Bold, Black, Super).                                                                                             | CLAUDE.md Section 14: drop everything else from the build.                                                                                                                          |
| D17 | 2026-10-10 | ESLint is pinned to 9.                                                                                                                                                                                         | `eslint-plugin-jsx-a11y` does not yet support ESLint 10.                                                                                                                            |
| D18 | 2026-10-10 | Prisma 7.10 with the `prisma-client` generator, `prisma.config.ts` for URLs and `@prisma/adapter-pg` at runtime.                                                                                               | Prisma 7 removed `url` and `directUrl` from the schema file. The `schema` option of the adapter selects `gistroom_dev` or `gistroom_test`.                                          |
| D19 | 2026-10-10 | The copy checker allows the copyright, registered and trademark signs.                                                                                                                                         | Unicode classes them as pictographic, but they are legal marks, not emoji.                                                                                                          |
| D20 | 2026-10-10 | All pages render per request (`await connection()` in the root layout).                                                                                                                                        | A nonce based CSP cannot protect prerendered HTML, whose scripts would carry no nonce and be blocked. Public pages still revalidate data and stay server rendered for SEO.          |
| D21 | 2026-10-10 | `npm audit` reports high findings in `mysql2` and `deepmerge-ts`, pulled in by the Prisma CLI. They are reviewed exceptions in `scripts/audit.mjs` with an expiry of 2027-01-10.                               | Gistroom never uses MySQL and the CLI merges only our own config. Any other high advisory fails CI.                                                                                 |
| D22 | 2026-10-10 | The CSP allows two style hashes (vaul drawer CSS and the empty style tag it inserts first), and the root layout sets `window.__webpack_nonce__`.                                                               | vaul cannot take a nonce. A unit test recomputes the hash from node_modules and fails when vaul changes its CSS.                                                                    |
| D23 | 2026-10-10 | Header links to /features, /rooms, /safety, /about, /login and footer pages point at routes built in later phases.                                                                                             | Phase 0 ships the landing shell only. These links 404 until Phase 1 (login) and Phase 6 (public pages).                                                                             |
| D24 | 2026-10-10 | Light mode is the default. Dark is opt in through a Light, Dark, System control, and only System follows the device.                                                                                           | Owner preference after reviewing both. Supersedes the auto dark rule in CLAUDE.md Section 13.                                                                                       |
| D25 | 2026-10-10 | Gistroom is built by @oyedokunken (https://www.oyedokun.dev/). No company is credited.                                                                                                                         | Owner correction. Removed from footer, JSON-LD, LICENSE and CLAUDE.md.                                                                                                              |
